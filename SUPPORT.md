# Support

Start with the [README](README.md) for installation and usage. Inside Tervy,
open **Cmd-P → Setup and Prerequisites** to see which shell and agent CLIs are
available. Agent CLIs need to be installed and signed in separately.

For a reproducible problem, open a [GitHub issue](https://github.com/jringeisen/tervy/issues)
with the Tervy version or commit, macOS version, agent CLI and version if
relevant, steps to reproduce, what happened, and what you expected. Mention
whether the app came from a local review build or a signed release. If it is a
UI problem, a screenshot with private content removed is helpful.

Diagnostics are stored in `~/Library/Logs/DevDesk`. Review and redact them
before sharing. Never post credentials, project source, terminal output,
meeting audio or transcripts, or agent conversations. For a possible security
issue, use [SECURITY.md](SECURITY.md) instead of a public issue.

Meeting recording is experimental in v1. If it fails, check the selected
meeting in Library for its saved audio and retry option before deleting it.
