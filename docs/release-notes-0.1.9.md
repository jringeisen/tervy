# Tervy 0.1.9

Text areas now grow and shrink to fit their content, including wrapped lines.
This applies to note content, the new-note dialog, skill content, supporting
files, and meeting notes. Very long content remains scrollable once the field
reaches its height limit.

## Install or update

Open **Settings** in Tervy and check for updates, then choose **Install update**.
Tervy asks before stopping running sessions.

For a new installation, download the Apple Silicon DMG from this release, open it,
and drag Tervy to Applications. Tervy supports Apple Silicon Macs running macOS
15 or later. Experimental meeting recording requires macOS 26 or later.

See the [README](https://github.com/jringeisen/tervy#readme) for your first
project and optional coding agent setup.
