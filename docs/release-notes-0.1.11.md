# Tervy 0.1.11

Saved notes in **Library → Notes** now open as rendered Markdown. Click the
pencil icon next to the note title to edit the title or Markdown. **Save**
shows the updated preview, and **Discard** returns to the last saved version.
New notes open directly in the editor.

To try it, create a note with a Markdown heading, a bulleted list, and a fenced
code block. Save it, then use the pencil icon to make a change and save again.

## Install or update

In Tervy, choose **Settings → Check for updates → Install update**. Tervy asks
before stopping running sessions. For a new installation, open the Apple Silicon
DMG from this release and drag Tervy to Applications.

Tervy supports Apple Silicon Macs on macOS 15 or later. Experimental meeting
recording and Teams reminders require macOS 26 or later.
