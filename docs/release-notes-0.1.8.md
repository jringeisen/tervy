# Tervy 0.1.8

This update makes the sidebar match light mode. Its background, project panels,
selected rows, dividers, section icons, and labels now use light colors with
readable contrast. Dark mode keeps its existing appearance.

## Install or update

If you already have Tervy 0.1.7, open **Settings** when the update badge appears
and choose **Install update**. Tervy asks before stopping running sessions.

For a new installation, download the Apple Silicon DMG from this release, open it,
and drag Tervy to Applications. Tervy supports Apple Silicon Macs running macOS
15 or later. Experimental meeting recording requires macOS 26 or later.

See the [README](https://github.com/jringeisen/tervy#readme) for your first
project and optional coding agent setup.
