# Tervy 0.1.7

First public beta for Apple Silicon Macs running macOS 15 or later.

Tervy brings project terminals, processes, and coding agents into one workspace. This release adds a shared Notes library, skill browsing and editing, improved meeting and agent workflows, and visual refinements including the sidebar status glow.

## In-app updates

This is the first build with in-app updates. Tervy checks for new releases and marks the Settings gear when one is available. Open Settings to check manually or install an update. Tervy asks before stopping running sessions for installation.

If you have an earlier Tervy build, replace it with this DMG once. Later releases can be installed from the app.

## Install

Download `Tervy-0.1.7-macos-arm64.dmg`, open it, and drag Tervy to Applications. Quit an older Tervy build before replacing it. Existing local data is migrated on first launch; back up important data before upgrading.

Coding agents are optional and require their own CLIs and sign-in. Meeting recording is experimental and requires macOS 26 or later.

See the [README](https://github.com/jringeisen/tervy#readme) for setup, backup, and support details.
