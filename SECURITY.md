# Security policy

Security fixes currently target the main branch. After the first public
release, this file will list supported release versions.

Please do not put an exploit, token, project content, terminal output, or
meeting transcript in a public issue. When the repository is public and private
vulnerability reporting is enabled, use **Security → Report a vulnerability**
on GitHub. If that action is unavailable, open an issue asking the maintainer
for a private contact method without disclosing the details.

Useful report details include the affected version or commit, macOS version,
steps to reproduce using synthetic data, impact, and any suggested mitigation.
The maintainer will coordinate disclosure after a fix is available.
